# E08 – Paper-first editor

**Phase:** 4 · **Depends on:** E07-01 to E07-04 · **Status:** implementation complete; manual device/usability validation pending · **GitHub:** [#166](https://github.com/maltinapro/pdfcraft/issues/166)

## Goal
Replace the two tabs ("Invoice" / "Sender & design") and the long form with the zone concept: four color-coded zones, a guided first run, returning users start where something is missing, and the real PDF preview becomes a way to navigate ("the paper is the form").

## Context / links
- [Design guide](../16-design-guide.md) section 2 (binding), section 9 (what to take from the owner's M3 demo).
- Today: `Workspace.tsx` (four-zone flow, issue summary, `jumpTo`, preview double buffering, desktop splitter, compact Form/Preview tabs, stepper and sticky footer), `InvoiceForm.tsx`, `DocumentForm.tsx`, `SettingsForm.tsx`, `ItemsEditor.tsx`, `MasterDataPickers.tsx`, `PostageSection.tsx`, `PdfCanvasPreview.tsx`, `lib/documents.ts` (`DOC_SPECS`), `lib/validate.ts`.
- Zone geometry for zones 3 and 4 needs the backend (Typst label positions); no customer data is returned or stored.

## Definition of done
- All six document types are edited through zones on desktop and mobile; the five-task protocol shows fewer taps and less time than the E07-05 baseline; no feature of the old editor is lost (drafts, master data pickers, postage, signature, issue jumps, download, archive entry).

## Decisions
- The editor (zone model, forms, zone bar/panels, preview with overlay, items zone) lives in the package `@maltinapro/editor` (`frontend/packages/editor`, #221): `Workspace.tsx` is now `PaperEditor.tsx` there and takes an `EditorAdapter` instead of reading storage or calling the API; the file names in the issue list above are relative to `frontend/packages/editor/src/components/`. See its `README.md`.
- Zone 3/4 geometry only for preview requests (`?zones=1` → header `X-Pdfcraft-Zones`); API consumers see no change.

**M3 wizard follow-up.** The first E08 pass did not match the intended design: "Sender & look" appeared twice on mobile, the heading ran behind the fixed navigation, the bottom navigation duplicated the browser bar, and nested rounded frames cost space. The editor was reworked into a minimal Material Design 3 wizard (design guide 2.2/2.4): stepper with short labels and per-step zone color, flat step panels with dividers, filled fields, a tonal footer, Form | Preview tabs and no bottom navigation. The PDF zone overlay is unchanged. Checked in Chromium with Pixel 7 emulation at 320/390 px and at 768/1440 px (DE/EN, light/dark). Step 1 is split into *Company & bank* and *Logo & look*, the download button in the app bar is hidden on the last step, and notes are shown only on their own step. E08-07 stays open until the human five-task comparison and real-device checks are recorded.
