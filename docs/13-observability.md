# Observability

Logs, metrics and dashboards for the Grafana/Prometheus/Loki stack. This guide grows with each step; the sections below describe what is implemented.

## Logging

All components write **one JSON object per line to stdout**, so Loki (via Promtail/Alloy) can ingest them without parsing rules beyond `| json`.

| Component | Format | Notes |
| --- | --- | --- |
| backend | JSON (`tracing`) | `RUST_LOG` sets the level (default `info`), `LOG_FORMAT=text` gives readable local output |
| frontend (nginx) | JSON access log | `frontend/nginx.conf`: `time`, `service`, `event`, `method`, `path`, `status`, `bytes`, `duration_s` |
| Anubis | JSON (its own `slog` output) | unchanged |

**Privacy:** no customer data, no client IPs, no user agents and no query strings are logged. Only route templates (`/v1/invoices`, never raw paths), status codes, timings and the non-secret token id/kind/plan. The token secret is never logged.

### Backend fields

Every line has `timestamp`, `level`, `target` and `message`/`event`. Important `event` values:

| `event` | Level | Extra fields |
| --- | --- | --- |
| `startup` | info | `listen`, `version`, `store`, `paid_tokens_enabled`, `free_rate_limit_per_minute`, `max_concurrent_compiles` |
| `http_request` | info (`/health`: debug) | `method`, `route`, `status`, `duration_ms`, and for authenticated requests `token_id`, `token_kind` (`free`/`paid`), `token_plan`, `token_age_s` |
| `invoice_generated` | info | `endpoint` (`single`/`bulk`), `invoices`, `token_id`, `token_kind`, `token_plan`, `duration_ms`, `size_bytes` |
| `token_created` / `token_extended` | info | `token_id`, `token_kind`, `token_plan`, `reason`, `until` |
| `rate_limited` | warn | token fields, `wait_secs` |
| `auth_failed` | warn | `reason` |
| `valkey_error`, `valkey_connect_failed` | error/warn | `error` |
| `facturx_skipped` | warn | `error` |

### Loki labels

Keep **stream labels** low-cardinality and put everything else in the JSON body. The chart's pods already carry the labels you want to promote (`namespace`, `app_kubernetes_io_component` = `backend`/`frontend`/`anubis`/`valkey`, `container`, `pod`). Do **not** make `token_id`, `route` or `event` labels; filter on them at query time:

```logql
# all errors of the backend
{namespace="pdfcraft", app_kubernetes_io_component="backend"} | json | level="ERROR"

# invoices generated by paid tokens, slower than 1 s
{app_kubernetes_io_component="backend"} | json | event="invoice_generated" | token_kind="paid" | duration_ms > 1000

# rate-limited requests per token
sum by (token_id) (count_over_time({app_kubernetes_io_component="backend"} | json | event="rate_limited" [1h]))

# configurator page views (frontend access log)
sum(count_over_time({app_kubernetes_io_component="frontend"} | json | path="/app/index.html" | status="200" [1d]))
```
