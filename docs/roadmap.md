# Roadmap

Derived from the business plan ("Businessplan PDFCraft", digitalrechnung.jetzt, sections 5 and 7) and checked against the current code. It lists only **code changes** that are worth doing now. Marketing, finance, legal and sales work is not part of it.

Status: `open` · `in progress` · `done`. After every finished epic or issue, update this file and the epic file. Conventions and GitHub workflow: [epics/README.md](epics/README.md).

GitHub issues are created **phase by phase** (epic issue + one sub-issue per task, labels `epic` / `task` / `phase-N`). Created so far: phase 1 (E01 #101, E02 #105, E03 #108 with their sub-issues).

## Current state (what already exists)

- Per-minute rate limits per token (`PAID_PLANS`), compile queue with load shedding, bulk limits per plan.
- Purchase page with renewal and cancelling, token info via `GET /v1/token`.
- Backup/restore page ("Daten & Sicherung") with reminder, archive, drafts.
- One layout for six document types (DIN 5008), accent color, font, footer, logo, signature image.
- Landing page with meta tags and JSON-LD; Helm demo chart (operator-managed Valkey supported).
- E-invoice XML (EN 16931, XRechnung) generated by the backend, validated with Mustang in CI (E01: fixed corpus of invoices and credit notes).

## Claims in the plan to correct before they are published

- "Mustang validation integrated": done by E01 for a fixed corpus of invoices and credit notes in CI; the claim covers those documents, not every possible input.
- "Internetmarke with your own Portokasse" as a selling point: off by default, never verified against the live Deutsche Post API, and it is open whether partners may use end-customer Portokasse logins ([14](14-internetmarke-integration.md)). Do not advertise it before that is verified.
- "Pre-validated compliance certificate" for enterprise customers: no such certificate exists; the CI result from E01 is the most the project can show.
- "< 10 ms": true for typical documents (about 5 ms for 3 items, about 28 ms for 60 items); say "typically".
- "29 €/year and 3.90 €/month": the product launches at 24.00 € and 2.90 € (`PAID_PRICES`); the 29 € plan price and the finance figures are an owner decision, not a code task.
- The license is MIT (checked); a separate commercial module is not needed now.
- The finance plan's largest line (API customers) assumes the API tiers; they can be sold via `PAID_PLANS` without a monthly quota (see above).
